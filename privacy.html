隐私政策 / Privacy Policy

← 返回首页 Home

我们收集什么 / What we collect

不收集任何数据。本应用不在开发者设备之外运行，没有网站、没有后端服务器、没有分析统计、没有遥测、没有广告，也不存储任何日志。

No data is collected. This application does not run outside the developer's own device. There is no website, no backend server, no analytics, no telemetry, no advertising, and no log storage.

访问哪些 Google 数据 / Which Google data is accessed

本应用仅使用 Google Drive API 的 https://www.googleapis.com/auth/drive 权限范围，用于读取、创建、修改和删除授权用户本人 Google 账号中的文件。该授权仅由开发者本人对自己的账号授予。

The app uses only the https://www.googleapis.com/auth/drive OAuth scope to read, create, modify and delete files in the authorising user's own Google account. This authorisation is granted by the developer to their own account only.

数据去向 / Where data goes

  • 文件仅在授权用户自己的 Google Drive 与其自己的本地存储之间传输，不经过任何第三方服务。
  • OAuth 令牌仅保存在开发者本人的本地配置文件中（权限 600），不上传、不共享。
  • 不与 Google 之外的任何方共享数据；不出售数据。

Files move only between the authorising user's own Google Drive and their own local storage, never through a third-party service. OAuth tokens are stored only in the developer's local config file (mode 600), never uploaded or shared. No data is shared with any party other than Google, and no data is ever sold.

撤回授权 / Revoking access

任何时候都可以在 Google 账号 → 第三方与应用 中移除对本应用的访问权限；也可以直接删除本地配置文件。撤回后本应用立即失去全部访问能力。

Access can be revoked at any time via Google Account → Security → Third-party apps with account access, or by deleting the local configuration file. Once revoked, the app loses all access immediately.

儿童隐私 / Children's privacy

本应用不面向 13 岁以下儿童，也不主动收集任何人的个人信息。

This application is not directed at children under 13 and does not knowingly collect personal information from anyone.
